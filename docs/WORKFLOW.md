# Production workflow

1. Put originals in `input/`; compute a hash if provenance matters.
2. Run the doctor and ffprobe inspection. Record source facts in the project folder.
3. Extract or transcribe audio locally and validate the word timeline.
4. Read the transcript, listen, and write the editorial summary and beat plan.
5. Generate pause candidates. Approve keep intervals only after listening around each boundary.
6. Cut a new media file, remap transcript timestamps, and verify A/V duration.
7. Build scenes from meaning: hook, argument, examples, contrast, payoff and CTA.
8. Add captions from edited time and review every line break.
9. Add music and SFX with speech as the priority. Record asset origin and license.
10. Render a review master. Inspect extracted frames and watch the whole video with sound.
11. Fix, render a new revision, normalize, run technical QC, and repeat visual review.
12. Deliver the approved MP4 separately; keep source, intermediates and final outputs distinct.

The project folder is the handoff record. It should explain why each cut, graphic and sound exists so a new Claude session or human editor can resume without guessing.
