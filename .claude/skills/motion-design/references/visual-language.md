# Visual language selection

| Meaning | Useful visual | Usually avoid |
| --- | --- | --- |
| Contrast | Side-by-side cards, aligned bars | Unrelated stock footage |
| Progress | Circle or bar tied to real duration | Decorative looping spinner |
| Process | Ordered steps and connecting arrows | All steps moving at once |
| Statistic | Counter plus context and source | Unsupported exact percentage |
| Warning | High-contrast callout, brief hold | Shaking every element |
| Quote | Restrained type, speaker attribution | Typewriter effect on long copy |
| CTA | One action, calm final hold | Multiple competing buttons |
